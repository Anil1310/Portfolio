# 🌟 Anil Kumar Chahar — Portfolio Website

> Modern, dark glassmorphic personal developer and data portfolio.

## 🚀 Live Demo & Deployment

This project is built with HTML5, Vanilla CSS, and JavaScript. It is 100% compatible with **GitHub Pages**:

1. Go to your repository on GitHub: [github.com/Anil1310/Portfolio](https://github.com/Anil1310/Portfolio)
2. Click **Settings** → **Pages** (on the left menu).
3. Under **Build and deployment** > **Branch**, select `main` and `/ (root)`.
4. Click **Save**.
5. Your portfolio will be live at:
   👉 **`https://anil1310.github.io/Portfolio/`**

## 🛠️ Tech Stack & Highlights

- **Aesthetics**: Glassmorphism, cyber neon accents, responsive layout.

- **Performance**: Vanilla CSS & JavaScript, zero heavy frameworks, sub-second load time.
